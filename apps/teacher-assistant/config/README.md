# 本机课程连接配置

将 `course-connections.example.json` 复制为 `course-connections.local.json` 后再填写真实课程 ID、CPI、班级白名单和已核验的页面入口名称。这个本机文件已被 Git 忽略，不应上传到简历演示或共享仓库。

不允许填写账号、密码、Cookie、Token 或学生信息。教师仍须在可见浏览器中自行完成登录与安全验证。

填写后运行 `npm run validate:profiles`。校验通过只代表配置格式可用于后续本机门禁，不代表平台页面已核验，也不会连接学习通。

日常使用时通过 `npm run local` 启动网页与本机任务网关。网关仅监听本机 `127.0.0.1`，只开放已登记的任务入口；没有有效配置或教师端登录时，会返回“未获取”或“需人工登录”。
