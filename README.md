# 学习通自动化脚本仓库

Carey 的学习通自动化项目，按业务功能整理，包含脚本项目与教师浏览器扩展。

当前教师扩展试用版：[v0.41.2 下载](https://github.com/nohookcarey/Autochaoxing/releases/tag/v0.41.2) · [安装更新说明](输出成果/教学运营自动化系统/docs/安装更新说明_v0.41.2.md) · [真实批改脱敏汇总](输出成果/教学运营自动化系统/docs/真实批改脱敏汇总_v0.41.2.md)。本轮61份成绩已独立核验，132份材料留人工；章节测试及跨校现场验收仍待完成。

## 仓库大纲

```text
输出成果/
├── 普通作业批改/
├── 章节测试批阅/
├── 章节创建/
├── 作业截止日期批量修改/
├── 教学运营自动化系统/
└── 版本沿革.md
```

| 项目 | 用途 | 推荐入口 |
| --- | --- | --- |
| 教学运营自动化系统 | 教师审核工作台、AI批改建议、本机教学辅助与受控提交（试用版） | [安装与使用](输出成果/教学运营自动化系统/README.md)；[下载版本](https://github.com/nohookcarey/Autochaoxing/releases) |
| 普通作业批改 | 扫描待批、采集评分依据、批量评分和复扫 | `run_with_playwright_cli.sh` |
| 章节测试批阅 | 发现章节测试、批阅、审计和定向修复 | `run_chapter_workflow.sh` |
| 章节创建 | 根据 JSON 数据创建或更新课程章节 | `run_chapter_create_workflow.sh` |
| 作业截止日期批量修改 | 扫描目标作业、修改截止日期并回读验证 | `run_deadline_workflow.sh` |

所有登录凭据均通过环境变量传入，不在仓库中保存真实账号、密码或登录状态。
