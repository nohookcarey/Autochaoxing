# 学习通自动化脚本仓库

Carey 的学习通自动化项目，按业务功能整理为四个可独立使用的脚本项目。

## 仓库大纲

```text
输出成果/
├── 普通作业批改/
├── 章节测试批阅/
├── 章节创建/
├── 作业截止日期批量修改/
└── 版本沿革.md
```

| 项目 | 用途 | 推荐入口 |
| --- | --- | --- |
| 普通作业批改 | 扫描待批、采集评分依据、批量评分和复扫 | `run_with_playwright_cli.sh` |
| 章节测试批阅 | 发现章节测试、批阅、审计和定向修复 | `run_chapter_workflow.sh` |
| 章节创建 | 根据 JSON 数据创建或更新课程章节 | `run_chapter_create_workflow.sh` |
| 作业截止日期批量修改 | 扫描目标作业、修改截止日期并回读验证 | `run_deadline_workflow.sh` |

所有登录凭据均通过环境变量传入，不在仓库中保存真实账号、密码或登录状态。
