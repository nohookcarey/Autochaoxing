# 历史独立工具

普通教师请使用[当前教师助手](../apps/teacher-assistant/README.md)，按[安装指南](../INSTALL.md)安装。以下目录保留原有开发参考，不继承当前扩展的全部审核门禁，不作为同事推荐运行入口。

| 目录 | 保留内容 |
|---|---|
| [assignments](assignments/README.md) | 普通作业旧脚本、历史课程适配与诊断 |
| [chapter-tests](chapter-tests/README.md) | 章节测试旧脚本及诊断 |
| [chapter-builder](chapter-builder/README.md) | 章节创建工具 |
| [deadlines](deadlines/README.md) | 作业截止时间旧工具 |
| [attendance](attendance/README.md) | 签到异常及表格辅助 |

公开版本不附带账号密码、登录态或真实课程配置。需要复用时重新配置并确认任务范围与规则；旧版写入限制和已停用入口继续保留。历史日期目录及占位脚本保留用于追溯，不代表当前支持或验收。
