# v0.41.3 发布审查与验收边界

日期：2026-10-24。公开试用版（prerelease）。

本版仅修改附件分类、原生附件适配、静态材料读取及回归测试。ZIP逐项检查目录、路径、CRC、长度、大小与嵌套限制，未知文件及超限拒绝评分；XLSX读取所有工作表和缓存公式，图片、图表、嵌入、外部连接和无缓存仍转人工。普通网页链接保留为身份绑定的作答证据，真实HTML文件与下载控件不降级为网页链接。没有增加域名权限，未运行学生程序。

355项回归测试与构建通过，失败0；新增ZIP、XLSX和普通网页链接测试。脱敏扩展64文件，与受审源码一致，两个私有配置置空；安装ZIP摘要已写入安装说明。发布源码使用确定的Git文件清单生成独立快照，工作目录中无关的未跟踪文件不纳入。

本轮新增111份真实普通作业写入及独立回读，累计172份；全页复扫剩21份人工。会话中的OCR、转换PDF和完整源码分段辅助不进入通用扩展发布包；不能据此宣称扩展已有跨平台OCR、任意DOCX图形读取或全部场景覆盖。

简历脱敏曾有片段进入会话工具输出，已修正规则并在真实汇总如实记录；安装包和公开源码不得包含这些片段、学生原文件或逐人成绩。当前声明仅为发布内容检查通过，不替代通用脱敏认证。

章节、多题、Windows Chrome/Edge、Mac指定浏览器及至少两校教师现场验收仍待完成。跨平台CI仍为待启用模板，不修改工作流权限；GitHub仓库、Release与匿名回下载状态以发布回执为准。
