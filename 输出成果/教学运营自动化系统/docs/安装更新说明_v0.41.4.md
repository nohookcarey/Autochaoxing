# v0.41.4 安装与更新

从 GitHub v0.41.4 Release 下载 LearningTong-Teacher-Assistant-v0.41.4.zip，完整解压，在 Chrome/Edge 扩展管理页开启开发者模式并“加载已解压的扩展程序”，选中直接含 manifest.json 的目录。无需 Node.js。完整步骤见仓库根目录 INSTALL.md。

已有用户先结束批次，再在固定目录更新文件并重载扩展；重新采集范围、核对已提交结果，不用旧草稿直接提交。

本次修复网关来源与会话校验、单题/批量附件流式限额，安装包增加 MIT 和隐私政策；依旧手动安装，不含免费 API，不需服务器。可选 Codex 桥接仍需本机单独启动，仍为在线模型服务。

普通作业已有本机真实提交与独立回读证据；本轮未新增真实成绩写入。Windows Chrome/Edge、Mac 指定浏览器、章节测试、多题和两校教师现场仍待验收。不可读、超限、身份不清的材料转人工。
