## 安装与更新

1. 解压同目录的 `教学运营助手-浏览器扩展-v0.41.3.zip`，保留整个解压目录。
2. 在Chrome打开扩展管理页，或在Edge打开扩展管理页，启用“开发者模式”。
3. 首次安装选择“加载已解压的扩展程序”，选中直接包含 `manifest.json` 的文件夹。当前为手动安装包，不是一键商店安装。
4. 已安装的教师先结束当前批次；更新原安装目录中的文件后在扩展管理页点“重新加载”。不要在提交中途更新。重新加载会清除会话草稿，须重新采集并核对平台结果。
5. 登录学习通教师页面，打开工作台，核验课程、班级、任务与待批范围；配置并分别测试文本和图像能力，确认评分卡后生成建议。
6. 对照材料审核、选择答案并确认提交范围。默认不选中答案、只写分数；每份提交后回读，最后复扫剩余待批。
