# 学习通教师端场景覆盖矩阵 · v0.41.0

本轮交付37项教师场景的开发进度清单，**没有宣称全面覆盖或跨校验收完成**。范围按教师完整教学周期推进，参考超星教师帮助并结合既有产品功能；清单不是穷尽所有学校、权限与平台版本。新增6个可实际处理教师材料的本机工具。

“本机工具已实现”指输入、计算/检查、教师审核和导出已完成；不表示已有对应平台发布接口。“已有适配”仍受页面版本、配置与现场证据限制。“待开发”没有原生操作入口。

原生能力后续优先顺序：资料上传与目录核验 → 题库导入及作业/测验发布 → 课堂活动发布/结果读取 → 学情采集 → 考试与监考 → 课程建班/团队与迁移归档。写入适配须有本轮真实页面证据与教师审核，不能根据旧接口猜测成功。

仍需现场条件：教师确认本次学期、真实批改标准与选中项；至少两校教师提供可用课程和功能入口，分别完成安装/配置/真实结果核验。当前仅有本机Mac Ego Chromium证据，Windows Chrome/Edge与其他Mac浏览器尚未验收。

- 变动警示：按本轮继续开发要求扩展到教师完整教学周期；新本机工具、图像读取和进度清单不代表“所有学习通场景”已完成。学生端与教务管理端未纳入当前默认范围。
