# 教学运营助手 v0.41.2：安装、更新与版本说明

日期：2026-10-23。公开试用版；本机普通作业有真实提交与独立回读证据。Windows Chrome、Edge、指定Mac浏览器、章节测试真实提交和两校独立安装仍待现场验收。

## 安装与更新

1. 从项目GitHub Releases下载本版扩展ZIP，解压并保留整个文件夹；不要直接选ZIP。
2. Chrome打开“扩展程序→管理扩展程序”，Edge打开“扩展→管理扩展”；开启开发者模式，选择“加载已解压的扩展”，选中包含manifest.json的文件夹。
3. 首次安装后登录学习通教师端，打开目标课程、班级和具体作业的批阅列表，再从插件打开审核工作台。
4. 更新时保留旧版本文件夹作为回退备份。将原扩展指向本版文件夹或重新加载；关闭旧工作台，再打开新工作台，重新扫描、核对平台已有成绩。不要恢复旧会话评分草稿。
5. 每次只处理一门课、一个班、一份作业；先确认评分卡、材料范围和AI发送授权。审核建议后逐项选择，查看最终清单并确认。默认不选中任何答案，不写评语。

当前安装包采用浏览器允许的手动载入方式，没有免确认的一键安装程序。请保留解压目录，浏览器会继续从该目录读取插件文件。

## 使用本机Codex

- 先在本机正常登录Codex；本机连接服务使用该登录，不需要复制登录文件或提供Codex账号密码。
- 下载完整源码包，打开scripts目录：Windows使用“启动Codex连接.cmd”，Mac使用“启动Codex连接.command”。本机连接需要Node.js 22或更高版本；Mac启动器也会查找Codex自带的运行环境。
- 在扩展详情复制本插件ID，按启动窗口提示输入。打开窗口给出的connectionCodeFile，复制本次连接码，在审核工作台“系统设置→本机Codex”中填写并保存。默认不记住连接码。
- 保持连接窗口开启，先测试文本能力，再处理已授权且可靠脱敏的材料。关闭窗口后连接失效。材料经当前Codex登录发送给OpenAI。
- 本轮实际批改采用文本方式；未可靠脱敏的原图、扫描简历、含图材料和无法完整读取的压缩包保留人工处理。使用图像模型前须单独测试能力，测试通过也不等于所有附件已可读。

## 本版变化

- 原生答案图片改用同一提交绑定的原文件接口，核验对象、完整长度及限定下载来源；没有增加域名权限。
- 提交后使用独立标签页回读同一份答案的成绩和已批状态，不再切走原提交页而打断学习通延迟保存。
- 核验成功后回收原提交页，继续使用已核验列表页，隔离平台延迟跳转对下一份批改的干扰。仅重复只读核验，不自动重复提交。
- 修复网页工作台图标导入导致的构建停滞，保持原有界面；普通作业、考勤、改期等既有模块随完整回归检查。
- 完整构建和344项测试通过；安装包64份文件逐项核对，其中两份本机私有配置替换为空白模板。

## 结果如何看

“已核验”才表示平台同一提交的分数和已批状态已回读成功。“结果不确定”先回读，不再次点击提交。“待人工复核”不等于零分；无法读取不等于没有待批。最终查看全页复扫的剩余待批数，不能只看建议生成完成。

答案和草稿限浏览器本次会话，长期仅保留脱敏汇总（最多100条）。发布包不包含本次学生答案、身份、逐人分数或连接码。
