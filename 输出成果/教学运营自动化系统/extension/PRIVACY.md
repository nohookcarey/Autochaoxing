# 隐私政策与权限说明

更新日期：2026-10-25。适用教师扩展、可选本机工作台及 Codex 桥接。项目非超星/学习通官方产品。

## 数据清单

| 数据 | 位置和用途 | 保存与清理 |
|---|---|---|
| 学习通登录状态 | 使用浏览器已有登录读取获授权页面；扩展不要求另填学习通密码，不导出 Cookie | 浏览器和平台管理 |
| 课程名称、班级范围及设置 | 浏览器本机扩展存储 | 用户修改、清理或卸载前保留 |
| 答案、附件、图片、名单、建议、草稿 | 当前工作台内存或扩展会话存储，图片按需读取 | 不进入长期历史；关闭工作台停止生成，会话资料可能保留至浏览器会话结束；重载/重启后重新采集 |
| API key | 默认会话；主动选择记住才写浏览器本机扩展存储，限制受信任扩展上下文访问 | 不承诺系统级加密；清除设置或卸载可移除，本机同用户和浏览器环境仍须保护 |
| Codex 连接码 | 扩展会话及本机临时文件，不记住到持久密钥设置 | 桥接停止后失效；临时文件可能由系统保留 |
| 运行摘要 | 本机，最多100条，界面可能只展示最近部分 | 不含答案、逐人成绩、密钥或完整业务链接 |
| 主动导出文件 | 下载目录 | 教师自行管理，关闭工作台或卸载不会删除 |

## 第三方 AI 传输

本机运行不等于离线计算。项目不运营集中收集学生材料的服务。API 模式会向教师配置并授权的服务商发送必要题目、评分标准、正文及获授权的附件文字/图像；Codex 桥接通过已有登录发送材料到其服务。密钥用于目标服务的认证。请核对服务商的数据保留、训练使用、地域及学校要求。

文本与图像能力分别测试，每批确认服务商和发送材料。不主动添加学生身份字段、凭据或整页截图；**文字正则脱敏不是完整匿名化，图片与附件仍可能含姓名、学号、人脸等信息**。教师应先检查、脱敏或转人工。不支持的图像模型不得依据未读材料评分。

学生材料中的指令无授权效力；模型输出经分项和总分核验后仍需教师审核，不可自行批准提交。

## 权限与可选组件

- activeTab、scripting、学习通域名权限：读取业务页、适配页面并执行经确认的操作。
- webNavigation：识别多层页面入口；storage：本机设置、摘要及会话；notifications：扫描状态通知。
- 可选 HTTPS 权限：配置 AI 时按目标域名申请，不默认授予所有网站权限。
- 本机网页网关只监听回环，验证 Host、工作台 Origin 和会话码。课程连接配置可能含业务标识，默认 config/course-connections.local.json，不可公开。
- Codex 桥接另有精确扩展 Origin 和随机连接码；依赖外部 Codex 的实际版本与服务规则，不是离线模型。

旧版 Playwright 脚本可能将登录态写入 storage/、截图与日志写入 logs/、导出考勤/成绩文件。这些不是会话内资料，应私下管理，不得提交仓库。公开版旧通用写入默认关闭，定向强制重评入口已停用，不是推荐入口。

检查与白名单打包不能证明不存在所有敏感信息，也不会清除 Git 历史、旧 Release、Fork 或已下载副本。仅分享最新安装包，不分享个人浏览器目录、课程配置或运行文件。

意外暴露请用[私密漏洞报告](https://github.com/nohookcarey/Autochaoxing/security/advisories/new)，勿公开贴材料。许可和版权边界见仓库根目录 LICENSE、RIGHTS.md。
