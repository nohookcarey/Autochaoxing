# 教学运营助手浏览器扩展（脱敏发布包）

- v0.41.1修复同名不同源附件误去重、UTF-8乱码与未知附件误读、评分卡变更后旧提交核验；发布源码排除本机配置、备份与个人演示素材，依赖更新并补充CI；详见仓库内审查报告。真实成绩提交、跨校与指定浏览器仍待验收。
- 本包不含真实课程 ID、CPI、班级标识、账号、Cookie、学生信息或运行记录。
- 默认提供连接检测、作业待批、截止时间、课程概览、章节结构和班级成绩聚合概览等通用只读能力。
- 自动导航和旧页面自恢复仅作用于已授权的学习通域名，不访问其他网站。
- 章节测试与签到功能依赖本机已验证配置；脱敏发布包默认隐藏对应按钮。
- 独立审核工作台支持普通作业与章节测试：核验范围、确认评分卡、批量建议、教师审核选中、确认提交、独立回读。仅处理待批，保留已有成绩。
- 教师自行配置兼容 AI API 并授权 HTTPS 域名。图像能力单独测试；每批答案与附件需授权发送。默认只提交分数，评语另选。
- v0.36.0新增教师评分卡库（版本、导入导出）、少量样本评分校准及基于有效审核分项的讲评稿。加载模板须再次确认；校准不自动调分或提交，讲评不引用学生原文、不自动发布。
- v0.37.0新增教学待办总览、未交与迟交名单核验及催交通知草稿。待办标明历史时间；名单需全部范围/分页/人数确认，不支持的页面转教师导入。姓名学号仅会话使用，导出需确认；通知本机生成、不自动发送。
- v0.38.0新增本批得分统计、待处理与异常清单、脱敏教师工作报告/分布CSV。区分教师已确认与平台已核验样本，排除失效数据；清单只定位不自动重试，导出须教师确认，历史复扫时间缺失时不显示零待批。
- v0.41.0新增课程管理中的题库审核、按题型组卷（学生卷与教师答案卷独立导出）、课堂活动准备/匿名分组/选人、学情快照、权重试算与原总评对照、课程文件SHA-256清单，以及37项教师场景进度清单。支持UTF-8 CSV文件导入，编码错误不截断读取；资料只保留在当前工作台；导出须教师确认，变化后失效；学情与试算只导出脱敏汇总。均为本机辅助，未接通原生发布和题库导入。DOCX新增受限内嵌PNG/JPEG/WebP读取及ZIP完整性核验，浮动/裁剪、图表和其他未支持结构转人工。
- v0.40.1接入教师页原生DOCX内嵌附件读取，核对文件标识、大小、完整正文及提交前内容变化；仅允许现场核验的下载来源，未支持来源转人工。已完成且有有效平台成绩的答案跳过。真实AI评分与提交仍需教师评分卡及审核确认。
- v0.40.0新增本机Codex接入（官方app-server、沿用已有登录）、本机连接码仅会话使用、分别测试文本与图像。需单独启动本机桥接并保持运行；不含登录凭据。修复Chrome保存数据后的字段排序误判。内嵌附件未取得原文件时明确待人工复核并阻止评分提交；真实DOCX批改、真实提交和跨校仍待验收。
- v0.39.0新增课程管理中的任务说明检查、要求与评分分项关联检查、可编辑/打印学生任务说明。教师填写资料，缺少计分关联或分值冲突阻止生成；关键词提示不等于语义审查。修改后重新确认导出，不调用AI、不读取学生答案、不自动发布，资料仅本工作台保留。
- 答案与草稿仅在本次浏览器会话保留。密钥默认会话使用；主动记住时本机保存不宣称加密。
- 首版代码与模拟验收不代替真实平台、Windows浏览器与跨校试用验收。
- 签到表与成绩表在生成前显示预览，成绩只允许学号匹配，生成后回读核对且不覆盖原文件。
- 在 Chromium 浏览器的扩展管理页选择“加载已解压的扩展程序”，指向本目录。
- 实际使用前先在扩展内保存课程名称和班级白名单，并在可见浏览器登录学习通、打开目标课程教师主页。
- 单条作业改期仅通过唯一目标预演和一次性确认执行；课程内容写入未开放。工作台提交须教师审核与最终清单确认。
