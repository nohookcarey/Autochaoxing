# 学习通教学运营助手（本机扩展与演示工作台）

这是一个仅在教师个人电脑上运行的教学运营工作台。真实学习通页面操作由本机浏览器扩展完成，不需要域名、云服务器或远程后端；系统默认只读。

当前版本 **v0.41.1（试用补丁版）**。普通作业/章节测试审核工作台、评分卡库、结果统计及六个教师周期本机工具已实现；原生发布、考试监考、迁移和两校现场验收仍有缺口，不宣称全部学习通场景覆盖。

GitHub发布位于仓库的 `输出成果/教学运营自动化系统/`。正式安装包从仓库Releases下载；解压后通过Chrome/Edge开发者模式“加载已解压的扩展程序”安装，更新后重新采集平台范围。下载来源和安装方式不等于指定浏览器现场验收。需要开发时使用Node.js 22或更高版本，运行 `npm ci`。

v0.41.1修复同名不同源附件漏读、文本编码错误/未知格式误判可读，以及评分卡改变后旧提交核验失效；补充发布脱敏/第三方字节完整性门禁、独立测试配置和跨平台CI模板（当前未启用）。密钥、身份、学生材料与本机备份不进入发布源码。

## 浏览器扩展：只读扫描与教师确认写入

扩展目录为 `extension/`。在 Chrome 或 Ego 浏览器的“扩展程序 → 开发者模式 → 加载已解压的扩展程序”中选择该目录。不要直接打开 `extension/popup/popup.html`；它只是扩展内部页面，只有从浏览器工具栏的扩展图标打开时才拥有扫描权限。

1. 教师自行登录学习通，并打开目标课程教师主页；扩展会按任务自动进入作业、章节、统计或班级活动页面。
2. 点击扩展图标，在顶部“AI 助手”输入一句话发起任务；或在“课程管理”新增或选择课程，再填写课程名称和班级白名单。
3. 可直接使用连接检测、作业待批、截止时间清单、章节测试待批、签到异常、课程概览、章节结构和成绩概览。“签到异常”与“成绩管理”支持导入 `.xlsx`：先显示工作表、匹配人数和目标列预览，教师确认后生成新文件，并在下载前重新读取核对；成绩表必须全部通过学号匹配。
4. 扩展会枚举课程的多层 frame 和同窗口业务标签页。升级后若旧页面尚未加载新脚本，会仅在学习通域名内补注入必要的只读扫描与导航脚本，无需刷新课程页。
5. 扫描结果保存在扩展本机存储中，可导出脱敏报告。页面或范围不完整时返回“未获取”；发现会话失效与可见登录页时返回“需人工登录”；已确认是教师业务页但必要入口消失时返回“页面结构变化”；只有范围完整核验后才返回“采集到”或“确认无数据”。

`v0.19.0` 已适配学习通当前签到教师页的两种结构：活动列表页和班级列表页。`v0.20.0` 进一步兼容课程导航中的 `javascript:` 伪链接：保留学习通原有点击处理，同时阻止浏览器执行被 CSP 拒绝的伪链接。若学生级记录缺少可核验学号，仍返回“未获取”并停止后续回填。

已结课课程可在课程范围中直接归档，归档只隐藏于当前课程列表，不删除课程名称或班级白名单；可随时恢复，且至少保留一门当前课程。“任务记录”可按“全部、需处理、已完成”筛选最近 20 条本机记录，点击记录只回看状态与原因，不保存学生明细。

当前扩展还提供单条作业截止时间的受控修改：可在作业管理表单中选择班级、填写精确作业标题和新时间，也可使用自然语言。两种入口都必须经过唯一匹配预演、一次性确认与列表回读。单题AI面板只生成建议并由教师应用，不点击平台提交；独立审核工作台另有教师确认清单后的受控提交入口，每份提交后独立回读。

`v0.34.0` 新增扫描状态反馈：作业待批扫描完成后，扩展图标角标显示待批总数（超过 99 显示 99+，无待批自动清除）；每次扫描完成弹出系统通知，可切走窗口后台等待；各功能卡片标题旁显示上次扫描时间（如“待批 5 分钟前”），悬停可查看该次摘要，课程切换后各自独立记录。

`v0.34.1` 恢复课程概览与章节结构扫描，补齐新增功能测试；AI API 改为按配置域名主动授权，附件默认不发送并限制为学习通可信域名；AI 评分改为“生成建议 → 教师应用 → 教师提交”；表格回填增加预览、成绩学号强匹配和生成文件回读。

## 启动

在本项目目录运行：

    npm run local

网页工作台运行在 http://localhost:4173/，本机任务网关只监听 127.0.0.1:4174。扩展的真实扫描不依赖该网关。

## 三分钟演示顺序

1. 展开扩展底部“演示与导出”，开启“脱敏演示”。
2. 点击“扫描待批作业”，查看脱敏的范围、状态、证据和汇总结果。
3. 输入“查看签到异常”或“查看待批测试”，体验 AI 对话进入白名单只读任务。
4. 点击“修改单条截止时间”，查看“预演 → 确认 → 模拟写入 → 独立回读”流程。
5. 在结果页导出脱敏运行报告和系统架构图，用于简历或面试展示。

演示模式不会连接学习通，也不会显示真实课程、课程 ID、CPI、账号、Cookie、学生身份、成绩或链接。

## 真实课程使用边界

- 在“课程管理”维护课程、班级白名单与启用任务。
- 扩展只保存课程名称、班级白名单、必要的本机功能配置与运行摘要，不保存学习通账号、密码、Cookie 或 Token。
- 真实扫描前必须在可见浏览器完成登录，并通过当前课程、班级和页面入口的只读核验。
- 页面未获取、班级范围不明或页面结构变化时，系统只会显示原因，不会误报“确认无数据”。
- 单条截止日期修改必须执行预演、确认和独立回读；批改不得绕过教师审核，工作台仅提交已确认并选中的答案。表格回填只生成经过回读的新文件，不覆盖原文件。
- AI请求需教师确认材料与服务商；可用自配API或本机Codex桥接。单题附件默认关闭，批量图文材料另行授权；密钥默认只在会话使用，主动记住时保存于浏览器本机并限制扩展访问。

## 验证

    npm test
    npm run build
    npm run verify:publication
    EXTENSION_RELEASE_DIR="/绝对路径/浏览器扩展_脱敏发布包_v0.41.1" npm run verify:release

测试覆盖演示数据脱敏、AI 意图与权限限制、附件可信域名、运行记录、课程归档与恢复、课程概览、章节结构、表格匹配与回读门禁、跨 frame/跨标签页扫描、自动导航、登录状态边界、受控改期和站点打包。`npm test` 同时执行原网页—扩展一致性契约，当前 9/9 项真实交互已覆盖。`verify:release` 会逐文件核对源码与发布包、确认两份私有配置已清空，并再次执行隐私模式扫描。


## v0.35.0 批改审核工作台（试用版）

插件弹窗新增“打开批改审核工作台”。从已登录的目标班级批阅列表核验范围，无需编辑课程脚本；支持评分卡确认、文字/文档/图像建议、逐份审核与选中、最终清单确认、受控提交、逐份回读及全分页复扫。只处理待批，保留已有成绩，评语默认不提交。

答案与草稿仅放在浏览器会话；关闭工作台可恢复会话，中断提交先核验，重启/重载后重新采集。密钥默认会话使用，主动记住时本机保存且不宣称加密。

`npm run test:batch` 覆盖身份、量规、状态、权限和重复提交；浏览器模拟验收与自动化测试不能替代真实扩展或平台测试，已取得证据与待验收事项见 `docs/`。

正式试用前需补齐真实Chromium扩展权限运行、Windows Chrome/Edge、Mac及两校教师的真实课程验收。页面结构或章节测试总分提交入口不匹配时停止，不猜测控件。安装包与正式使用/验收说明见学习通自动化项目的输出成果目录。
