# 学习通普通作业批改脚本

用于学习通教师端普通作业批改，不包含章节测试。

## 当前目标

- 先扫描，再决定是否补批
- 只处理白名单班级
- 不写评语
- 每次执行后必须输出此次评分表
- 已评分分布明显分叉时停止

## 目录用途

- `login_xuexitong.js`
  - 登录并进入课程作业列表
- `scan_assignment_pending.js`
  - 扫描待批作业与班级汇总
- `collect_assignment_review_basis.js`
  - 提取待批清单、已评分分布、样本依据
- `batch_grade_assignment.js`
  - 按显式 `jobs` 执行补批
- `run_with_playwright_cli.sh`
  - 统一入口：`login|scan|collect|grade|validate`
- `validate_reuse_tripwire.sh`
  - 三重验证
- `course_context.md`
  - 新学期课程参数模板与复用边界

## 默认可直接使用状态

- 默认登录账号和密码已经写入 `login_xuexitong.js`
- 默认课程参数已清空，复用前必须填写
- 统一从 `run_with_playwright_cli.sh` 进入，不再直接从零拼命令
- 若需切换课程，优先改课程上下文或显式环境变量，不改诊断脚本

## 当前支持版本

- 默认主入口：当前目录
- 课程专用版本：`自然语言处理_2026_05_27`

其中：

- 当前目录用于通用的学习通普通作业批改
- `自然语言处理_2026_05_27` 用于 `自然语言处理` 的课程专用批改与验收

## 默认执行顺序

1. 先执行 `validate`
2. 再执行 `scan`
3. 提取批阅依据
4. 判断能否自动补批
5. 再执行 `grade`
6. 批后复扫并输出评分表

## 复用要求

- 先确认本轮评分准则
- 先确认目标班级范围
- 先看样本，再决定是否开批
- 批后必须复扫
